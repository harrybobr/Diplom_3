# Stellar Burgers: Web Application Testing

### Описание проекта
Этот проект представляет собой тестирование веб-приложения **Stellar Burgers**. Тестирование охватывает ключевую функциональность, такую как регистрация, вход, переходы между разделами и работу конструктора бургеров. Тесты реализованы с использованием паттерна **Page Object** для удобного управления элементами страниц. Тестирование проводится в браузерах **Google Chrome** и **Яндекс.Браузер**, а результаты отображаются в **Allure-отчете**.

### Тестируемые сценарии
Проект включает следующие тесты:

- **Регистрация:**
  - Успешная регистрация нового пользователя.
  - Проверка ошибки при вводе некорректного пароля (менее 6 символов).

- **Вход в систему:**
  - Вход через кнопку "Войти в аккаунт" на главной странице.
  - Вход через кнопку "Личный кабинет".
  - Вход через кнопку в форме регистрации.
  - Вход через кнопку в форме восстановления пароля.

- **Переходы в личный кабинет и назад:**
  - Переход по клику на "Личный кабинет".
  - Переход из личного кабинета в раздел "Конструктор".
  - Переход на главную страницу через логотип Stellar Burgers.

- **Выход из аккаунта:**
  - Выход из аккаунта через кнопку "Выйти" в личном кабинете.

- **Раздел "Конструктор":**
  - Переходы между разделами "Булки", "Соусы", "Начинки" и проверка их работоспособности.

### Инструменты и технологии
Для тестирования использованы следующие технологии:

- **Java 11** — основной язык программирования.
- **Selenium WebDriver** — для взаимодействия с веб-элементами.
- **JUnit/TestNG** — для написания и выполнения тестов.
- **Allure** — для генерации отчетов о тестировании.
- **Maven** — для управления зависимостями и сборки проекта.

### Page Object Model (POM)
Все страницы приложения описаны с использованием паттерна **Page Object**, что упрощает поддержку тестов и работу с веб-элементами. Для каждой страницы создан отдельный класс с соответствующими методами для взаимодействия с элементами.

### Структура проекта
- **Page Object**: В проекте используется отдельный пакет для Page Object, каждая страница веб-приложения описана в отдельном классе.
- **Тесты**: Тесты разделены по функциональным сценариям и организованы в соответствующие классы. Все тесты лежат в папке `test/java`.

### Запуск тестов
Для локального запуска всех тестов можно использовать следующую команду:
```bash
mvn clean test
```

### Отчёт по тестированию
После выполнения тестов можно сгенерировать отчёт Allure:
```bash
mvn allure:serve
```

### Jenkins CI/CD
Как и в предыдущих заданиях, проект интегрирован с Jenkins для автоматического запуска тестов и генерации отчетов. Поддержка тестирования в браузерах **Google Chrome** и **Яндекс.Браузер**.

### Установка проекта
1. Клонируй репозиторий:
   ```bash
   git clone <ссылка-на-репозиторий>
   ```
2. Установи зависимости с помощью Maven:
   ```bash
   mvn clean install
   ```
3. Запусти тесты:
   ```bash
   mvn test
   ```

### Оценка проекта
Проект соответствует следующим критериям:
- Для каждого функционального сценария создан отдельный класс с тестами.
- Все тесты успешно запускаются в **Google Chrome** и **Яндекс.Браузере**.
- Тесты проверяют основные сценарии: регистрация, вход, переходы между страницами и работу конструктора.
- Тесты построены на основе паттерна **Page Object**, каждый элемент страницы описан в соответствующем классе.
- Названия локаторов и тестов понятны и отражают суть проверяемого функционала.
- Все тесты независимы друг от друга и проверяют конкретные сценарии.
- Отчет **Allure** добавлен в пул-реквест.
